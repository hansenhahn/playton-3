# Personagens — Índice Geral | Professor Layton and the Unwound Future

> **Pasta:** `Spec/Personagens/` — Dossiês para tradução não-mecânica
> **Fonte primária:** `Spec/Capitulo_00_Prologo.md` → `Spec/Capitulo_14.md` + `Spec/Extras_*.md` (dumps LSCR `Textos Originais/txt/uk/*`)
> **Objetivo:** garantir que cada falante tenha voz distinta na localização PT-BR. Tradução mecânica = perder bordões, registro e humor.

## Como usar este índice

Cada arquivo segue o mesmo template:

1. **Identificação** — Tag LSCR JP, nome EN/PT-BR, primeira aparição
2. **Papel Narrativo** — função no mistério (quem engana, quem é enganado)
3. **Personalidade** — traços psicológicos observáveis nos dumps
4. **Registro Linguístico** — tom, formalidade, sotaque, ritmo
5. **Bordões & Tiques** — frases recorrentes literais (EN original)
6. **Relações** — como trata e é tratado
7. **Arco / Evolução** — muda ou é máscara?
8. **Notas de Tradução PT-BR** — O que PRESERVAR, o que ADAPTAR, o que NUNCA fazer

> **Regra de ouro:** nunca traduza bordão literalmente se perder ritmo. Adapte mantendo função (ex.: `BZZT! DING DING DING!` = efeito sonoro de quiz, não traduzir para `ZUMBIDO`).

## Convenções de Tags LSCR preservadas

- `<Vxxxx>` = dublagem — manter ritmo mais teatral (frases curtas, pausas `<W>`)
- `<K>` = `Hmm...` silencioso — traduzir como hesitação, não cortar
- `<N>` = nome do jogador; `<N1>` = nome do papagaio (escolha do jogador) — **nunca traduzir placeholder**
- `Tee hee hoo!` (Mrs. Cogg), `Keh heh heh!` (Stachenscarfen), `Hyaah haa haa!` (Bemora) = risadas identitárias — manter onomatopeia adaptada, não normalizar para `haha`
